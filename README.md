# Presupuestos Eléctricos

App para hacer presupuestos eléctricos por salidas, materiales y bloques, con PDF para el cliente.

- **En el navegador o instalada desde la web:** https://dannyvillarm.github.io/Presupuesto-Electrico/ ("Agregar a pantalla de inicio").
- **Android (APK):** https://github.com/dannyvillarm/Presupuesto-Electrico/releases/download/android/Presupuestos-Electricos.apk

Los datos se guardan en el equipo donde uses la app. Usa "Exportar mis datos" y "Cargar una copia" (en Mi empresa) para pasarlos de un equipo a otro.

El APK se arma solo con GitHub Actions (`.github/workflows/android.yml`) cada vez que cambia la app.
