# Presupuestos Eléctricos

App web para hacer presupuestos eléctricos por salidas, materiales y bloques, con PDF para el cliente.
Funciona sin internet y se puede instalar en el teléfono ("Agregar a pantalla de inicio").
Los datos se guardan en el navegador del equipo; usa "Exportar mis datos" / "Cargar una copia" para pasarlos de un equipo a otro.
